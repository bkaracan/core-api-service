Kurumsal Servis Katmanı Standartları

Spring Boot 4.1.1 mikroservislerinde iş mantığı soyutlaması (Interface & Implementation), bildirimsel transaction sınırları (@Transactional(readOnly = true)), sıfır HTTP sızıntısı, Dual-ID (UUID publicId) ve yüksek hızlı Mockito birim test rehberi.

1 Arayüz ve Gerçekleştirim Ayrımı (Interface & Implementation)

Kurumsal mikroservislerde Controller katmanı asla somut servis sınıflarına doğrudan bağımlı olmamalıdır. Dependency Inversion prensibi gereği Controller yalnızca sözleşmeye (Interface) bağımlıdır.

❌ Doğrudan Somut Sınıf Enjeksiyonu
  • Sıkı bağlılık (Tight Coupling) yaratır; Controller iş mantığının tüm iç detaylarına maruz kalır.
  • Controller katmanı test edilirken servis davranışını mock'lamak veya taklit etmek zorlaşır.
  • AOP proxy'leri, Decorator deseni veya Caching katmanları şeffaf biçimde araya giremez.
✅ Interface + Impl Ayrımı (Kurumsal Standart)
  • Gevşek bağlılık (Loose Coupling): Controller yalnızca metot imzalarını ve dönüş tiplerini bilir.
  • Mocking kolaylığı: Controller testlerinde @MockitoBean ProductService ile kusursuz test edilebilirlik.
  • Gerektiğinde yeni bir gerçekleştirim (örneğin ProductServiceV2Impl) Controller'a dokunmadan devreye alınabilir.
📁 Paket Hiyerarşisi Standardı
com.enterprise.coreapi.service/
├── ProductService.java               # Sözleşme Arayüzü (Interface)
└── implementation/ (veya impl/)
    └── ProductServiceImpl.java       # Somut Gerçekleştirim (@Service)

2 Katı Transaction Sınırları & readOnly Performansı

Veritabanı transaction sınırları yalnızca ve yalnızca Servis katmanında yönetilir. Controller veya Repository katmanına @Transactional konulması yasaktır.

Sınıf Seviyesinde Varsayılan: @Transactional(readOnly = true)
1. Hibernate okuma işlemlerinde Dirty-Checking (kirli kontrol) mekanizmasını tamamen kapatır. Nesnelerin ilk durumlarının (snapshot) bellekte tutulmasını engelleyerek RAM tüketimini ve CPU maliyetini minimize eder.
2. Master/Replica veritabanı altyapılarında JDBC sürücüsü okuma sorgularını otomatik olarak Read-Replica düğümlerine yönlendirir.

Yazma Metotlarında Açık Bildirim: @Transactional(rollbackFor = Exception.class)
Veri oluşturan, güncelleyen veya silen metotların üzerinde açıkça tanımlanmalıdır. Varsayılan Spring davranışında checked exception'lar rollback tetiklemez; rollbackFor = Exception.class eklenerek tüm hata senaryolarında veri tutarlılığı güvenceye alınır.

⚠️ Kritik Tuzak: Self-Invocation (Kendi Kendini Çağırma)

Spring'in @Transactional mekanizması CGLIB proxy nesneleri üzerinden yürütülür. Aynı sınıf içindeki readOnly = true bir metot, yine aynı sınıftaki @Transactional bir yazma metodunu doğrudan (this.saveInternal()) çağırdığında proxy atlanır ve transaction hiç başlamaz! 

// ❌ YANLIŞ: Proxy atlanır, save() transaction DIŞINDA çalışır!
public void processBatch() {
    this.createProduct(req); // CGLIB proxy devre dışı kalır!
}

// ✅ DOĞRU: Transactional metotlar Controller veya farklı bir servis üzerinden çağrılmalıdır.

3 Sıfır HTTP Sızıntısı (Zero HTTP Leaks)

Servis katmanı salt iş mantığından ibarettir. Protokolden bağımsız olmalı; ister REST Controller'dan, ister bir Kafka tüketici (consumer) dinleyicisinden, ister bir Quartz zamanlayıcısından çağrılabilecek saflıkta kalmalıdır.

Katman / Alan ❌ Kesinlikle Yasaklı Unsurlar ✅ Kurumsal Standart & Kabul Edilen Tipler
Giriş Parametreleri HttpServletRequest, HttpHeaders, @RequestParam, @PathVariable Saf Java 21 Record Request DTO'ları (CreateProductRequest), UUID publicId, Pageable
Dönüş Değerleri ResponseEntity<T>, HttpStatus, ApiResponse<T> Saf Java 21 Record Response DTO'ları (ProductResponse), Page<ProductResponse>, void
Hata Yönetimi return null;, hata kodlu String dönmek, HTTP Status dönmek Domain Exception fırlatmak: throw new ResourceNotFoundException(...) veya throw new ApiException(...)

4 Dual-ID & Güvenlik Entegrasyonu (UUID publicId)

IDOR (Insecure Direct Object Reference) saldırılarını engellemek ve veritabanı performansını korumak için geliştirdiğimiz Dual-ID deseni Servis katmanında yönetilir.

🌐 Dış API Sorguları (UUID publicId)

Dış istemci (Frontend / Mobil) servisi UUID publicId ile çağırır: 

Product product = productRepository.findByPublicId(publicId)
    .orElseThrow(() -> new ResourceNotFoundException("Product", "publicId", publicId));

Ardışık olmayan rastgele UUID, saldırganların /products/1, /products/2 şeklinde verileri taramasını imkansız kılar.

⚡ İç Veritabanı İlişkileri (Long id)

İç ilişkiler, foreign key bağlantıları ve JOIN işlemleri servis katmanı içinde Long id ile yürütülür: 

// Foreign key bağlarken iç id kullanılır (maksimum B-Tree performansı):
item.setProductId(product.getId());

İç Long id dış dünyaya, API response DTO'larına veya loglara ASLA sızdırılmaz.

5 Soft Delete & Concurrency (Optimistic Locking)

Kurumsal sistemlerde veriler fiziksel olarak silinmez; denetim iziyle birlikte mantıksal olarak işaretlenir. Eşzamanlı güncellemelerde ise Optimistic Locking veri bütünlüğünü korur.

🗑️ markDeleted() ile Denetimli Mantıksal Silme

Servis katmanı silme isteği aldığında fiziksel repository.delete() çağırmaz. Varlığın markDeleted(currentUser) metodunu tetikler: 

@Override
@Transactional(rollbackFor = Exception.class)
public void deleteProduct(UUID publicId) {
    Product product = findProductByPublicId(publicId);
    String currentUser = securityAuditorAware.getCurrentAuditor().orElse("SYSTEM");
    
    product.markDeleted(currentUser);
    productRepository.save(product);
}

Hibernate 6 seviyesindeki @SQLRestriction("deleted = false") filtresi sayesinde sonraki okuma sorgularında bu ürün otomatik olarak görünmez.

🔒 Eşzamanlı Güncelleme Çakışması (Lost Updates Koruması)

İki farklı yönetici aynı anda aynı ürünü güncellemek istediğinde:

  1. Yönetici A ve B ürünü okur (versiyon = 1).
  2. Yönetici A fiyatı günceller ve kaydeder (versiyon = 2 olur).
  3. Yönetici B eski veri üzerinden kaydetmeye çalıştığında Hibernate ObjectOptimisticLockingFailureException fırlatır.
  4. GlobalExceptionHandler devreye girer ve Yönetici B'ye temiz bir 409 CONFLICT yanıtı döner. Veri ezilmesi engellenir!

6 MapStruct Delegasyonu & Constructor Injection

Servis metodlarının içi manuel get/set kodlarıyla kirletilmez. Dönüşümler MapStruct mapper'larına, bağımlılıklar ise değişmez (immutable) constructor injection'a bırakılır.

Örnek Servis Sınıfı İskeleti 
@Slf4j
@Service
@RequiredArgsConstructor // private final alanlar için constructor üretir (@Autowired yasak!)
@Transactional(readOnly = true) // Sınıf varsayılanı: yüksek hızlı okuma
public class ProductServiceImpl implements ProductService {

    private final ProductRepository productRepository;
    private final ProductMapper productMapper;
    private final SecurityAuditorAware securityAuditorAware;

    // Metotlar...
}

7 Yüksek Hızlı Mockito Birim Testleri (Unit Tests)

Servis katmanı iş mantığı testlerinde asla ağır Spring ApplicationContext (@SpringBootTest) ayağa kaldırılmaz. Saf Mockito (@ExtendWith(MockitoExtension.class)) ile testler mikrosaniyeler içinde koşar.

com/enterprise/coreapi/service/implementation/ProductServiceImpl.java 
package com.enterprise.coreapi.service.implementation;

import com.enterprise.coreapi.common.config.SecurityAuditorAware;
import com.enterprise.coreapi.common.entity.Product;
import com.enterprise.coreapi.common.exception.ApiException;
import com.enterprise.coreapi.common.exception.ErrorCode;
import com.enterprise.coreapi.common.exception.ResourceNotFoundException;
import com.enterprise.coreapi.dto.request.CreateProductRequest;
import com.enterprise.coreapi.dto.request.UpdateProductRequest;
import com.enterprise.coreapi.dto.response.ProductResponse;
import com.enterprise.coreapi.mapper.ProductMapper;
import com.enterprise.coreapi.repository.ProductRepository;
import com.enterprise.coreapi.service.ProductService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.UUID;

@Slf4j
@Service
@RequiredArgsConstructor
@Transactional(readOnly = true)
public class ProductServiceImpl implements ProductService {

    private final ProductRepository productRepository;
    private final ProductMapper productMapper;
    private final SecurityAuditorAware securityAuditorAware;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public ProductResponse createProduct(CreateProductRequest request) {
        log.info("Creating product with code: {}", request.code());

        if (productRepository.existsByCode(request.code())) {
            log.warn("Product creation rejected: Duplicate code [{}]", request.code());
            throw new ApiException(ErrorCode.DUPLICATE_RESOURCE, "A product with code '" + request.code() + "' already exists");
        }

        Product product = productMapper.toEntity(request);
        Product savedProduct = productRepository.save(product);

        log.info("Product created successfully with publicId: {}", savedProduct.getPublicId());
        return productMapper.toResponse(savedProduct);
    }

    @Override
    public ProductResponse getProductByPublicId(UUID publicId) {
        log.debug("Fetching product by publicId: {}", publicId);
        Product product = findProductByPublicId(publicId);
        return productMapper.toResponse(product);
    }

    @Override
    public Page<ProductResponse> getAllProducts(Pageable pageable) {
        log.debug("Fetching paginated products: page={}, size={}", pageable.getPageNumber(), pageable.getPageSize());
        return productRepository.findAll(pageable)
                .map(productMapper::toResponse);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public ProductResponse updateProduct(UUID publicId, UpdateProductRequest request) {
        log.info("Updating product with publicId: {}", publicId);

        Product product = findProductByPublicId(publicId);
        productMapper.updateEntityFromRequest(request, product);
        Product updatedProduct = productRepository.save(product);

        log.info("Product updated successfully with publicId: {}", updatedProduct.getPublicId());
        return productMapper.toResponse(updatedProduct);
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void deleteProduct(UUID publicId) {
        log.info("Soft deleting product with publicId: {}", publicId);

        Product product = findProductByPublicId(publicId);
        String currentUser = securityAuditorAware.getCurrentAuditor().orElse("SYSTEM");
        product.markDeleted(currentUser);

        productRepository.save(product);
        log.info("Product soft-deleted successfully: publicId={}, deletedBy={}", publicId, currentUser);
    }

    private Product findProductByPublicId(UUID publicId) {
        return productRepository.findByPublicId(publicId)
                .orElseThrow(() -> {
                    log.warn("Product not found with publicId: {}", publicId);
                    return new ResourceNotFoundException("Product", "publicId", publicId);
                });
    }
}
src/test/java/com/enterprise/coreapi/service/ProductServiceImplTest.java 
package com.enterprise.coreapi.service;

import com.enterprise.coreapi.common.config.SecurityAuditorAware;
import com.enterprise.coreapi.common.entity.Product;
import com.enterprise.coreapi.common.exception.ApiException;
import com.enterprise.coreapi.common.exception.ResourceNotFoundException;
import com.enterprise.coreapi.dto.request.CreateProductRequest;
import com.enterprise.coreapi.dto.request.UpdateProductRequest;
import com.enterprise.coreapi.dto.response.ProductResponse;
import com.enterprise.coreapi.mapper.ProductMapper;
import com.enterprise.coreapi.repository.ProductRepository;
import com.enterprise.coreapi.service.implementation.ProductServiceImpl;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Nested;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.InjectMocks;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;

import java.math.BigDecimal;
import java.time.Instant;
import java.util.Optional;
import java.util.UUID;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;
import static org.mockito.ArgumentMatchers.any;
import static org.mockito.Mockito.*;

@ExtendWith(MockitoExtension.class)
@DisplayName("ProductServiceImpl Unit Tests")
class ProductServiceImplTest {

    @Mock
    private ProductRepository productRepository;

    @Mock
    private ProductMapper productMapper;

    @Mock
    private SecurityAuditorAware securityAuditorAware;

    @InjectMocks
    private ProductServiceImpl productService;

    @Nested
    @DisplayName("createProduct Tests")
    class CreateProductTests {

        @Test
        @DisplayName("Gecerli istek ile urun basariyla olusturulmalidir")
        void shouldCreateProductSuccessfully() {
            CreateProductRequest request = new CreateProductRequest("Laptop", "PROD-001", new BigDecimal("1500.00"), 10);
            Product entity = new Product();
            Product savedEntity = new Product();
            UUID publicId = UUID.randomUUID();
            savedEntity.setPublicId(publicId);

            ProductResponse expectedResponse = new ProductResponse(publicId, "Laptop", "PROD-001", new BigDecimal("1500.00"), 10, "ACTIVE", Instant.now(), Instant.now());

            when(productRepository.existsByCode("PROD-001")).thenReturn(false);
            when(productMapper.toEntity(request)).thenReturn(entity);
            when(productRepository.save(entity)).thenReturn(savedEntity);
            when(productMapper.toResponse(savedEntity)).thenReturn(expectedResponse);

            ProductResponse actualResponse = productService.createProduct(request);

            assertThat(actualResponse).isNotNull();
            assertThat(actualResponse.publicId()).isEqualTo(publicId);
            verify(productRepository).save(entity);
        }

        @Test
        @DisplayName("Mukerrer urun kodunda ApiException firlatilmalidir")
        void shouldThrowExceptionWhenProductCodeAlreadyExists() {
            CreateProductRequest request = new CreateProductRequest("Laptop", "PROD-001", new BigDecimal("1500.00"), 10);
            when(productRepository.existsByCode("PROD-001")).thenReturn(true);

            assertThatThrownBy(() -> productService.createProduct(request))
                    .isInstanceOf(ApiException.class)
                    .hasMessageContaining("already exists");

            verify(productRepository, never()).save(any());
        }
    }

    @Nested
    @DisplayName("getProductByPublicId Tests")
    class GetProductTests {

        @Test
        @DisplayName("Mevcut publicId ile urun basariyla donmelidir")
        void shouldReturnProductWhenPublicIdExists() {
            UUID publicId = UUID.randomUUID();
            Product product = new Product();
            product.setPublicId(publicId);
            ProductResponse expectedResponse = new ProductResponse(publicId, "Laptop", "PROD-001", new BigDecimal("1500.00"), 10, "ACTIVE", Instant.now(), Instant.now());

            when(productRepository.findByPublicId(publicId)).thenReturn(Optional.of(product));
            when(productMapper.toResponse(product)).thenReturn(expectedResponse);

            ProductResponse actualResponse = productService.getProductByPublicId(publicId);

            assertThat(actualResponse).isNotNull();
            assertThat(actualResponse.publicId()).isEqualTo(publicId);
            verify(productRepository).findByPublicId(publicId);
        }

        @Test
        @DisplayName("Bulunamayan publicId icin ResourceNotFoundException firlatilmalidir")
        void shouldThrowResourceNotFoundExceptionWhenPublicIdDoesNotExist() {
            UUID publicId = UUID.randomUUID();
            when(productRepository.findByPublicId(publicId)).thenReturn(Optional.empty());

            assertThatThrownBy(() -> productService.getProductByPublicId(publicId))
                    .isInstanceOf(ResourceNotFoundException.class)
                    .hasMessageContaining("Product not found");

            verify(productMapper, never()).toResponse(any());
        }
    }
}
