Kurumsal Test Stratejisi & Standartları

Spring Boot 4.1.1 mikroservislerinde sahte güven veren H2 veritabanını yasaklayan, gerçek PostgreSQL 16 container'ı üzerinde Testcontainers (@ServiceConnection) koşturan, saf Mockito birim testleri ve modern @MockitoBean WebMvc dilim test rehberi.

Java 21 LTS / Spring Boot 4.1.1 Pure Mockito Unit Tests (<20ms) Modern @MockitoBean WebMvc Slice No H2! Real PostgreSQL 16 Container Testcontainers @ServiceConnection AssertJ Fluent API

1 Üç Katmanlı Test Piramidi & H2 Database Yasağı

Kurumsal mikroservis test stratejisi hız, güvenilirlik ve üretim ortamı sadakatini dengeler.

⚡ 1. Birim Testler (Unit)

Kapsam: Servis katmanı iş kuralları.
Araç: JUnit 5 + Mockito.
Spring Context: YOK (Saf Java).
Çalışma Süresi: 5-20 milisaniye.

🍰 2. Dilim Testleri (Slice)

Kapsam: Controller (WebMvc) veya Repository (DataJpa).
Araç: @WebMvcTest + @MockitoBean.
Spring Context: Yalnızca ilgili dilim.
Çalışma Süresi: 200-500 milisaniye.

🐳 3. Entegrasyon (Integration)

Kapsam: Uçtan uca API, DB ve Flyway.
Araç: @SpringBootTest + Testcontainers.
Spring Context: Tam uygulama + PostgreSQL 16.
Çalışma Süresi: 1-3 saniye.

❌ Neden H2 Veritabanı Kesinlikle Yasaktır?

Yıllarca kullanılan H2 in-memory veritabanı, modern kurumsal mikroservislerde sahte bir güven illüzyonu yaratır ve canlı ortamda çökmelere neden olur:

Özellik / Senaryo ❌ H2 Database (In-Memory) ✅ Testcontainers PostgreSQL 16
Flyway Migration Postgres'e özgü DDL'lerde hata verir veya çalışmaz. Canlı ortamla %100 birebir aynı migration'ları koşar.
citext (Case-Insensitive) Desteklemez. Test patlar. Tam destekler, e-posta/kullanıcı adı testleri kusursuz geçer.
Soft Delete Kısmi İndeks WHERE deleted = false indeks sözdizimini tanımaz. Kısmi indeks performansını ve UNIQUE kuralını doğrular.
TIMESTAMPTZ & UUID Saat dilimi sapmaları (Timezone drift) yaşanır. UTC saat dilimine ve gen_random_uuid() fonksiyonuna tam sadık kalır.

2 Hızlı Birim Testler (Zero Spring Context in Unit Tests)

Servis katmanının iş mantığını test ederken @SpringBootTest KULLANILMAZ. Spring konteynerini ayağa kaldırmak test süresini katlayarak CI/CD pipeline'ını yavaşlatır.

Saf Mockito Standardı: @ExtendWith(MockitoExtension.class)
Spring context'i başlatılmadığı için yüzlerce servis testi yalnızca 1-2 saniye içinde tamamlanır. Bağımlılıklar (Repository, Mapper, AuditorAware) @Mock ile taklit edilir; test edilen sınıf @InjectMocks ile enjekte edilir.

3 Controller Web Dilim Testi & Modern @MockitoBean

HTTP sözleşmesini, URL haritalamalarını, `@Valid` bean validasyonunu ve hata yanıtlarını tüm uygulamayı ayağa kaldırmadan izole test eder.

Spring Boot 4.1.1 / Spring 6.2+ Devrimi: @MockitoBean
Eski Spring sürümlerinde kullanılan @MockBean ve @SpyBean anotasyonları Spring Boot 3.4+ ve 4.x ile birlikte kullanımdan kaldırılmıştır (deprecated). Artık doğrudan Spring Test Framework standardı olan org.springframework.test.context.bean.override.mockito.MockitoBean kullanılır.

🔍 WebMvc Dilim Testinin Doğruladığı Kritik Unsurlar
  • HTTP Status Kodları: Başarılı kayıtta 201 Created, okumada 200 OK, silmede 204 No Content.
  • Bean Validation Fail-Fast: Boş isim veya negatif fiyat gönderildiğinde Controller'a girmeden 400 Bad Request ve VALIDATION_ERROR dönmesi.
  • Envelope Formatı: Yanıtın kurumsal ApiResponse<T> sözleşmesine (success, data, error, timestamp) uygun paketlenmesi.

4 DataJpa Testi & Testcontainers @ServiceConnection

Özel JPQL sorguları, Hibernate mapping kuralları, `@SQLRestriction` soft-delete filtreleri ve kısmi indeksleri gerçek PostgreSQL üzerinde test eder.

Sıfır Konfigürasyon: @ServiceConnection
Spring Boot 3.1+ ile gelen @ServiceConnection anotasyonu sayesinde, test sınıfı içinde tanımlanan PostgreSQLContainer'ın dinamik portu ve JDBC URL'i Spring DataSource'a otomatik bağlanır. Manuel @DynamicPropertySource kodlarına gerek kalmaz!

5 Akıcı Doğrulama Standardı (AssertJ Fluent API)

Testlerde JUnit'in ilkel assertion metotları yerine okunabilirliği yüksek, hata anında detaylı teşhis sağlayan AssertJ assertThat() standardı zorunludur.

❌ İlkel JUnit Assertion (Yasaklı)
assertEquals("Laptop", res.name());
assertTrue(res.price().doubleValue() > 0);
assertNotNull(res.publicId());
assertFalse(res.deleted());

Hata anında: "expected: true but was: false" gibi anlamsız mesajlar üretir.

✅ AssertJ Fluent Assertion (Standart)
assertThat(res.name()).isEqualTo("Laptop");
assertThat(res.price()).isPositive();
assertThat(res.publicId()).isNotNull();
assertThat(res.deleted()).isFalse();

Hata anında nesnenin tüm alanlarını ve beklenen değerle farkını detaylı gösterir.

6 BDD Test İsimlendirme ve Given-When-Then Disiplini

Her test metodu kendini belgeleyen bir dokümandır. BDD standartlarında yapılandırılmalıdır.

📐 Standart Test Metodu Şablonu
@Test
@DisplayName("Gecerli istek ile urun basariyla olusturulmalidir")
void should_create_product_when_request_is_valid() {
    // given: Test girdileri ve mock davranışları hazırlanır
    CreateProductRequest request = new CreateProductRequest("Laptop", "PROD-001", new BigDecimal("1500.00"), 10);
    when(productRepository.existsByCode("PROD-001")).thenReturn(false);

    // when: Test edilen iş metodu tetiklenir
    ProductResponse actual = productService.createProduct(request);

    // then: Sonuçlar AssertJ ve Mockito verify ile doğrulanır
    assertThat(actual).isNotNull();
    assertThat(actual.code()).isEqualTo("PROD-001");
    verify(productRepository).save(any());
}

7 Üretime Hazır Kod Şablonları (Spring Boot 4.1.1)

Projede doğrudan kullanılabilecek tam ve doğrulanmış test sınıfları.

src/test/java/com/enterprise/coreapi/service/ProductServiceImplTest.java 
@ExtendWith(MockitoExtension.class)
@DisplayName("ProductServiceImpl Unit Tests")
class ProductServiceImplTest {

    @Mock
    private ProductRepository productRepository;

    @Mock
    private ProductMapper productMapper;

    @Mock
    private SecurityAuditorAware securityAuditorAware;

    @InjectMocks
    private ProductServiceImpl productService;

    @Test
    @DisplayName("Gecerli istek ile urun basariyla olusturulmalidir")
    void should_create_product_when_request_is_valid() {
        // given
        CreateProductRequest request = new CreateProductRequest("Laptop", "PROD-001", new BigDecimal("1500.00"), 10);
        Product entity = new Product();
        Product savedEntity = new Product();
        UUID publicId = UUID.randomUUID();
        savedEntity.setPublicId(publicId);

        ProductResponse expected = new ProductResponse(publicId, "Laptop", "PROD-001", new BigDecimal("1500.00"), 10, "ACTIVE", Instant.now(), Instant.now());

        when(productRepository.existsByCode("PROD-001")).thenReturn(false);
        when(productMapper.toEntity(request)).thenReturn(entity);
        when(productRepository.save(entity)).thenReturn(savedEntity);
        when(productMapper.toResponse(savedEntity)).thenReturn(expected);

        // when
        ProductResponse actual = productService.createProduct(request);

        // then
        assertThat(actual).isNotNull();
        assertThat(actual.publicId()).isEqualTo(publicId);
        verify(productRepository).save(entity);
    }
}
src/test/java/com/enterprise/coreapi/controller/ProductControllerTest.java 
@WebMvcTest(ProductController.class)
@DisplayName("ProductController WebMvc Slice Tests")
class ProductControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @Autowired
    private ObjectMapper objectMapper;

    // Spring Boot 4.1.1 standardı: @MockBean yerine @MockitoBean
    @MockitoBean
    private ProductService productService;

    @Test
    @WithMockUser
    @DisplayName("Gecerli istek ile 201 Created ve olusturulan urun donmelidir")
    void should_create_product_and_return_201_created() throws Exception {
        UUID publicId = UUID.randomUUID();
        CreateProductRequest request = new CreateProductRequest("MacBook Pro", "MBP-14", new BigDecimal("1999.00"), 5);
        ProductResponse response = new ProductResponse(publicId, "MacBook Pro", "MBP-14", new BigDecimal("1999.00"), 5, "ACTIVE", Instant.now(), Instant.now());

        when(productService.createProduct(any(CreateProductRequest.class))).thenReturn(response);

        mockMvc.perform(post("/api/v1/products")
                        .with(csrf())
                        .contentType(MediaType.APPLICATION_JSON)
                        .content(objectMapper.writeValueAsString(request)))
                .andExpect(status().isCreated())
                .andExpect(jsonPath("$.success").value(true))
                .andExpect(jsonPath("$.data.publicId").value(publicId.toString()))
                .andExpect(jsonPath("$.data.code").value("MBP-14"));
    }
}
src/test/java/com/enterprise/coreapi/repository/ProductRepositoryIntegrationTest.java 
@DataJpaTest
@Testcontainers
@AutoConfigureTestDatabase(replace = AutoConfigureTestDatabase.Replace.NONE)
@DisplayName("ProductRepository Integration Tests (PostgreSQL Testcontainers)")
class ProductRepositoryIntegrationTest {

    @Container
    @ServiceConnection
    static PostgreSQLContainer postgres = new PostgreSQLContainer<>("postgres:16-alpine");

    @Autowired
    private ProductRepository productRepository;

    @Test
    @DisplayName("publicId ile kayitli urun bulunabilmelidir")
    void should_find_product_by_public_id() {
        UUID publicId = UUID.randomUUID();
        Product product = new Product();
        product.setPublicId(publicId);
        product.setName("Monitor");
        product.setCode("MON-4K");
        product.setPrice(new BigDecimal("499.00"));
        product.setStock(20);
        product.setCreatedBy("TEST_USER");
        product.setLastModifiedBy("TEST_USER");

        productRepository.save(product);

        Optional<Product> found = productRepository.findByPublicId(publicId);

        assertThat(found).isPresent();
        assertThat(found.get().getCode()).isEqualTo("MON-4K");
    }
}
