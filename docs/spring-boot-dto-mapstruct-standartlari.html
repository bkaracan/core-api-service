Spring Boot 4.1.1 DTO & MapStruct Dönüşüm Standartları

Gevşek, mutable ve Lombok anotasyon kalabalığına boğulmuş sınıf tabanlı DTO'lar yerine Java 21'in doğal değişmezlik (immutability) ve bellek optimizasyonu sunan record yapılarını; Controller sınırında fail-fast Jakarta Bean Validation disiplinini ve derleme zamanında tip güvenli kod üreten MapStruct mimarisini standarda bağlayan kurumsal geliştirici kılavuzu.

AŞAMA 1

Mimari İlkeler & Tavizsiz Kurallar

Veri bütünlüğünü, güvenliğini ve tip güvenliğini korumak için belirlenen 4 temel kural.

1. Java 21 `record` Zorunluluğu
Tüm Request (*Request) ve Response (*Response) nesneleri istisnasız Java 21 record olarak tanımlanmalıdır.
  • Sınıf (class) tabanlı DTO'lar ve setter metodları kesinlikle yasaktır.
  • JVM seviyesinde doğal immutability ve thread-safety garantisi sunar.
  • Otomatik equals(), hashCode() ve toString() üretir.
2. Sıfır Entity Sızıntısı (Zero Entity Exposure)
JPA Entity modelleri asla Controller katmanına sızdırılamaz.
  • Entity'ler asla @RequestBody veya @ResponseBody olarak kullanılamaz.
  • Dönüşümler yalnızca Service katmanında MapStruct ile yürütülür.
  • Şifre hash'leri, veritabanı ID'leri veya iç alanlar dış dünyaya sızdırılmaz.
3. Fail-Fast Validation & Compact Constructor
Tüm giriş doğrulama kuralları Controller sınırında kesilir.
  • @NotBlank, @Size, @Positive vb. Request record bileşenlerinde tanımlanır.
  • Controller'da @Valid ile otomatik tetiklenir (400 Bad Request).
  • Çapraz parametre kontrolleri record'un Compact Constructor bloğunda handle edilir.
4. Compile-Time MapStruct Sözleşmesi
Runtime reflection yapan kütüphaneler (ModelMapper, BeanUtils) yasaktır.
  • MapStruct derleme zamanında saf Java byte-code üretir (sıfır runtime ek yükü).
  • unmappedTargetPolicy = ReportingPolicy.ERROR ile unutulan alanlar derleme anında yakalanır.
  • Kısmi güncellemeler için @MappingTarget ve IGNORE stratejisi uygulanır.

Maven pom.xml Yapılandırması

MapStruct ve Lombok derleme zamanı işlemcilerinin (annotation processor) çakışmasız çalışması için kesin yapılandırma.

pom.xml XML
<properties>
    <java.version>21</java.version>
    <org.mapstruct.version>1.6.3</org.mapstruct.version>
    <lombok-mapstruct-binding.version>0.2.0</lombok-mapstruct-binding.version>
</properties>

<dependencies>
    <!-- MapStruct Core -->
    <dependency>
        <groupId>org.mapstruct</groupId>
        <artifactId>mapstruct</artifactId>
        <version>${org.mapstruct.version}</version>
    </dependency>

    <!-- Jakarta Bean Validation -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-validation</artifactId>
    </dependency>
</dependencies>

<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-compiler-plugin</artifactId>
            <version>3.13.0</version>
            <configuration>
                <source>21</source>
                <target>21</target>
                <parameters>true</parameters>
                <annotationProcessorPaths>
                    <!-- 1. Lombok Processor -->
                    <path>
                        <groupId>org.projectlombok</groupId>
                        <artifactId>lombok</artifactId>
                        <version>${lombok.version}</version>
                    </path>
                    <!-- 2. Lombok-MapStruct Köprüsü (Sıralama kritiktir) -->
                    <path>
                        <groupId>org.projectlombok</groupId>
                        <artifactId>lombok-mapstruct-binding</artifactId>
                        <version>${lombok-mapstruct-binding.version}</version>
                    </path>
                    <!-- 3. MapStruct Processor -->
                    <path>
                        <groupId>org.mapstruct</groupId>
                        <artifactId>mapstruct-processor</artifactId>
                        <version>${org.mapstruct.version}</version>
                    </path>
                </annotationProcessorPaths>
                <compilerArgs>
                    <compilerArg>-Amapstruct.defaultComponentModel=spring</compilerArg>
                    <compilerArg>-Amapstruct.unmappedTargetPolicy=ERROR</compilerArg>
                </compilerArgs>
            </configuration>
        </plugin>
    </plugins>
</build>

Request DTO Sözleşmeleri (Records)

Jakarta Bean Validation anotasyonları ve Compact Constructor ile çapraz alan kural kontrolleri.

CreateProductRequest.java Java 21 Record
package com.enterprise.coreapi.dto.request;

import io.swagger.v3.oas.annotations.media.Schema;
import jakarta.validation.constraints.DecimalMin;
import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.NotNull;
import jakarta.validation.constraints.Size;
import org.jspecify.annotations.Nullable;

import java.math.BigDecimal;
import java.time.LocalDate;

@Schema(description = "Yeni ürün oluşturma istek sözleşmesi")
public record CreateProductRequest(

        @Schema(description = "Ürün adı", example = "MacBook Pro 16", requiredMode = Schema.RequiredMode.REQUIRED)
        @NotBlank(message = "Ürün adı boş bırakılamaz")
        @Size(min = 2, max = 100, message = "Ürün adı 2 ile 100 karakter arasında olmalıdır")
        String name,

        @Schema(description = "Ürün SKU kodu", example = "PRD-MBP16-001", requiredMode = Schema.RequiredMode.REQUIRED)
        @NotBlank(message = "SKU kodu zorunludur")
        @Size(min = 3, max = 30, message = "SKU kodu 3 ile 30 karakter arasında olmalıdır")
        String sku,

        @Schema(description = "Birim fiyat", example = "74999.99", requiredMode = Schema.RequiredMode.REQUIRED)
        @NotNull(message = "Fiyat bilgisi zorunludur")
        @DecimalMin(value = "0.01", message = "Fiyat sıfırdan büyük olmalıdır")
        BigDecimal price,

        @Schema(description = "Kategori ID", example = "10")
        @NotNull(message = "Kategori referansı zorunludur")
        Long categoryId,

        @Schema(description = "Kampanya başlangıç tarihi", example = "2026-10-01")
        @Nullable
        LocalDate campaignStartDate,

        @Schema(description = "Kampanya bitiş tarihi", example = "2026-10-15")
        @Nullable
        LocalDate campaignEndDate
) {
    // Fail-Fast Compact Constructor: Çapraz alan iş kuralı doğrulaması
    public CreateProductRequest {
        if (campaignStartDate != null && campaignEndDate != null && campaignEndDate.isBefore(campaignStartDate)) {
            throw new IllegalArgumentException("Kampanya bitiş tarihi başlangıç tarihinden önce olamaz");
        }
    }
}

Kurumsal MapStruct Mapper Mimarisi

Compile-time tip güvenli dönüşümler, @MappingTarget kısmi güncelleme ve derleme hatası garantisi.

ProductMapper.java MapStruct Interface
package com.enterprise.coreapi.mapper;

import com.enterprise.coreapi.dto.request.CreateProductRequest;
import com.enterprise.coreapi.dto.request.UpdateProductRequest;
import com.enterprise.coreapi.dto.response.ProductResponse;
import com.enterprise.coreapi.dto.response.ProductSummaryResponse;
import com.enterprise.coreapi.entity.Product;
import org.mapstruct.*;

import java.util.List;

@Mapper(
        componentModel = MappingConstants.ComponentModel.SPRING,
        unmappedTargetPolicy = ReportingPolicy.ERROR,
        nullValuePropertyMappingStrategy = NullValuePropertyMappingStrategy.IGNORE
)
public interface ProductMapper {

    /**
     * CreateRequest -> Product Entity Dönüşümü
     * ID ve audit alanları veritabanı/servis tarafından yönetildiğinden açıkça ignore edilir.
     */
    @Mapping(target = "id", ignore = true)
    @Mapping(target = "category", ignore = true) // Service katmanında yüklenir
    @Mapping(target = "active", constant = "true")
    @Mapping(target = "createdAt", ignore = true)
    @Mapping(target = "updatedAt", ignore = true)
    Product toEntity(CreateProductRequest request);

    /**
     * Product Entity -> ProductResponse DTO Dönüşümü
     */
    ProductResponse toResponse(Product entity);

    /**
     * Product Entity -> ProductSummaryResponse DTO Dönüşümü
     */
    ProductSummaryResponse toSummaryResponse(Product entity);

    /**
     * Liste Dönüşümü
     */
    List<ProductSummaryResponse> toSummaryResponseList(List<Product> entities);

    /**
     * Kısmi Güncelleme (Partial Update) Sözleşmesi
     * nullValuePropertyMappingStrategy = IGNORE sayesinde DTO'da null gelen alanlar entity'yi ezmez.
     */
    @Mapping(target = "id", ignore = true)
    @Mapping(target = "sku", ignore = true) // İş kuralı: SKU değiştirilemez
    @Mapping(target = "category", ignore = true)
    @Mapping(target = "createdAt", ignore = true)
    @Mapping(target = "updatedAt", ignore = true)
    void updateEntityFromDto(UpdateProductRequest request, @MappingTarget Product entity);
}

Service & Controller Entegrasyonu

Katı protokol sınırları: Service sadece saf Record DTO alır/döner, Controller HTTP zarfını yönetir.

ProductServiceImpl.java Pure Service
package com.enterprise.coreapi.service.impl;

import com.enterprise.coreapi.common.exception.ResourceNotFoundException;
import com.enterprise.coreapi.dto.request.CreateProductRequest;
import com.enterprise.coreapi.dto.request.UpdateProductRequest;
import com.enterprise.coreapi.dto.response.ProductResponse;
import com.enterprise.coreapi.dto.response.ProductSummaryResponse;
import com.enterprise.coreapi.entity.Product;
import com.enterprise.coreapi.mapper.ProductMapper;
import com.enterprise.coreapi.repository.ProductRepository;
import com.enterprise.coreapi.service.ProductService;
import lombok.RequiredArgsConstructor;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@RequiredArgsConstructor
public class ProductServiceImpl implements ProductService {

    private final ProductRepository productRepository;
    private final ProductMapper productMapper;

    @Override
    @Transactional
    public ProductResponse createProduct(CreateProductRequest request) {
        Product product = productMapper.toEntity(request);
        Product savedProduct = productRepository.save(product);
        return productMapper.toResponse(savedProduct);
    }

    @Override
    @Transactional(readOnly = true)
    public ProductResponse getProductById(Long id) {
        Product product = productRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Ürün bulunamadı: " + id));
        return productMapper.toResponse(product);
    }

    @Override
    @Transactional(readOnly = true)
    public Page<ProductSummaryResponse> getAllProducts(Pageable pageable) {
        return productRepository.findAll(pageable)
                .map(productMapper::toSummaryResponse);
    }

    @Override
    @Transactional
    public ProductResponse updateProduct(Long id, UpdateProductRequest request) {
        Product product = productRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Ürün bulunamadı: " + id));

        productMapper.updateEntityFromDto(request, product);
        return productMapper.toResponse(product);
    }
}
ProductController.java REST Controller
package com.enterprise.coreapi.controller;

import com.enterprise.coreapi.common.openapi.*;
import com.enterprise.coreapi.common.response.ApiResponse;
import com.enterprise.coreapi.common.response.PageResponse;
import com.enterprise.coreapi.dto.request.CreateProductRequest;
import com.enterprise.coreapi.dto.request.UpdateProductRequest;
import com.enterprise.coreapi.dto.response.ProductResponse;
import com.enterprise.coreapi.dto.response.ProductSummaryResponse;
import com.enterprise.coreapi.service.ProductService;
import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.tags.Tag;
import jakarta.validation.Valid;
import lombok.RequiredArgsConstructor;
import org.slf4j.MDC;
import org.springframework.data.domain.Pageable;
import org.springframework.data.web.PageableDefault;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/v1/products")
@RequiredArgsConstructor
@Tag(name = "Product Management", description = "Ürün kayıt, güncelleme ve listeleme uçları")
public class ProductController {

    private final ProductService productService;

    @PostMapping
    @Operation(summary = "Yeni ürün oluştur")
    @ApiCreateResponse
    public ResponseEntity<ApiResponse<ProductResponse>> createProduct(
            @Valid @RequestBody CreateProductRequest request
    ) {
        ProductResponse response = productService.createProduct(request);
        return ResponseEntity
                .status(HttpStatus.CREATED)
                .body(ApiResponse.success(response, MDC.get("traceId")));
    }

    @GetMapping("/{id}")
    @Operation(summary = "ID ile ürün detayı getir")
    @ApiGetResponse
    public ResponseEntity<ApiResponse<ProductResponse>> getProductById(@PathVariable Long id) {
        ProductResponse response = productService.getProductById(id);
        return ResponseEntity.ok(ApiResponse.success(response, MDC.get("traceId")));
    }

    @GetMapping
    @Operation(summary = "Sayfalı ürün listesi")
    @ApiGetResponse
    public ResponseEntity<ApiResponse<PageResponse<ProductSummaryResponse>>> getAllProducts(
            @PageableDefault(size = 20, sort = "id") Pageable pageable
    ) {
        PageResponse<ProductSummaryResponse> page = PageResponse.of(productService.getAllProducts(pageable));
        return ResponseEntity.ok(ApiResponse.success(page, MDC.get("traceId")));
    }

    @PatchMapping("/{id}")
    @Operation(summary = "Ürün bilgilerini kısmi güncelle")
    @ApiGetResponse
    public ResponseEntity<ApiResponse<ProductResponse>> updateProduct(
            @PathVariable Long id,
            @Valid @RequestBody UpdateProductRequest request
    ) {
        ProductResponse response = productService.updateProduct(id, request);
        return ResponseEntity.ok(ApiResponse.success(response, MDC.get("traceId")));
    }
}

Anti-Pattern Karşılaştırmaları (Doğru vs. Yanlış)

Sıkça yapılan mimari hatalar ve kurumsal çözüm modelleri.

❌ YANLIŞ: Mutable Sınıf DTO + Setter Amelesi
@Data
@NoArgsConstructor
@AllArgsConstructor
public class ProductDto {
    private Long id;
    private String name;
    private BigDecimal price;
}
// Risk: İş akışının ortasında bir geliştirici 
// dto.setPrice(new BigDecimal("0")) çağırarak veriyi bozabilir!
Mutable sınıflar thread-safe değildir ve kodun herhangi bir yerinde veri yapısının değiştirilmesine açıktır.
✅ DOĞRU: Java 21 İmmutable Record
public record ProductResponse(
        Long id,
        String name,
        BigDecimal price
) {
    // Doğal thread-safe, compile-time güvenceli, sıfır setter riski!
}
Record nesneleri oluşturulduktan sonra değiştirilemez (immutable), thread-safe ve JVM optimizasyonludur.
❌ YANLIŞ: JPA Entity'nin Controller'a Sızması
@PostMapping
public ResponseEntity<Product> create(@RequestBody Product product) {
    // Mass Assignment Açığı: İstemci payload içinde 
    // "id": 1 veya "active": true göndererek veri ezebilir!
    return ResponseEntity.ok(repository.save(product));
}
Veritabanı varlıklarının doğrudan Controller'a açılması ciddi güvenlik ve veri bütünlüğü riskleri doğurur.
✅ DOĞRU: Strict DTO & MapStruct İzolasyonu
@PostMapping
public ResponseEntity<ApiResponse<ProductResponse>> create(
        @Valid @RequestBody CreateProductRequest request
) {
    // MapStruct @Mapping(target="id", ignore=true) uygular!
    ProductResponse response = productService.createProduct(request);
    return ResponseEntity.status(CREATED).body(ApiResponse.success(response));
}
Yalnızca açıkça izin verilen alanlar içeri alınır, iç alanlar ve veritabanı ID'leri izole kalır.
❌ YANLIŞ: Reflection Araçları (ModelMapper/BeanUtils)
// ModelMapper veya Spring BeanUtils.copyProperties(source, target)
// Çalışma anında (runtime) alan isimlerini string ile arar:
// 1. Ağır CPU/bellek maliyeti (reflection overhead).
// 2. Alan ismi değiştiğinde sessizce null yutar, derleme hatası VERMEZ!
Reflection tabanlı kütüphaneler derleme zamanında tip kontrolü sağlayamaz ve çalışma anı performansını düşürür.
✅ DOĞRU: Derleme Zamanında Kod Üreten MapStruct
// MapStruct derleme zamanında doğrudan getter/setter kodu (.class) üretir.
// Sıfır reflection overhead!
// unmappedTargetPolicy = ERROR sayesinde alan adı değişirse DERLEME PATLAR!
Doğrudan Java metot çağrısı hızında çalışır ve tüm alan eşleşmelerini derleme anında garanti eder.

Kurumsal Mimari Kontrol Listesi (Checklist)

DTO ve Mapper katmanlarını commit etmeden önce kontrol edilmesi zorunlu standartlar tablosu.

Kriter Kodu Kontrol Maddesi Standart & Kural Açıklaması Durum
CHK-DTO-01 Java 21 `record` Zorunluluğu Tüm Request ve Response DTO'ları istisnasız record olarak tanımlanmalı; sınıf DTO ve setter kullanımı yasaklanmalıdır. Zorunlu
CHK-DTO-02 Zero Entity Exposure JPA Entity sınıfları asla Controller katmanında parametre (@RequestBody) veya dönüş tipi olamaz. Zorunlu
CHK-DTO-03 Fail-Fast Jakarta Validation Tüm kısıtlamalar (@NotBlank, @NotNull, @DecimalMin) Request Record'larında tanımlanmalı ve Controller'da @Valid ile tetiklenmelidir. Zorunlu
CHK-DTO-04 Compact Constructor Kontrolü Birbiriyle ilişkili parametrelerin mantıksal doğrulamaları (örn. tarih aralıkları) Record Compact Constructor'ında yapılmalıdır. Zorunlu
CHK-DTO-05 Compile-Time MapStruct ModelMapper/BeanUtils kullanımı yasaktır; tüm dönüşümler derleme anında kod üreten MapStruct ile yapılmalıdır. Zorunlu
CHK-DTO-06 Sıkı Hata Politikası unmappedTargetPolicy = ReportingPolicy.ERROR ayarlanmalı; eşleşmeyen tüm alanlar açıkça ignore = true tanımlanmalıdır. Zorunlu
CHK-DTO-07 Lombok-MapStruct Binding pom.xml altında lombok, lombok-mapstruct-binding ve mapstruct-processor sıralı olarak tanımlanmalıdır. Zorunlu
CHK-DTO-08 Kısmi Güncelleme Güvenliği PATCH/PUT metodlarında @MappingTarget ve NullValuePropertyMappingStrategy.IGNORE ile null alanların veriyi ezmesi engellenmelidir. Zorunlu
CHK-DTO-09 Saf Mapper Prensibi Mapper arayüzlerine DB Repository veya Service enjekte edilmemeli; veri tabanı sorguları ve iş mantığı Service katmanında kalmalıdır. Zorunlu
CHK-DTO-10 OpenAPI & JSpecify Record alanları @Schema ile dokümante edilmeli, null olabilir alanlar @Nullable ile işaretlenmelidir. Zorunlu
