Enterprise Identity & Access Management (IAM)

Modern Enterprise Spring Boot User Service with SSO & Social Federation Blueprint

Gelecekteki kurumsal Java Spring Boot projelerinde ortak çekirdek (core/starter) modül olarak kullanılmak üzere tasarlanmış; OAuth 2.1, OIDC 1.0, Social Login (Google & GitHub) kimlik federasyonunu, Just-In-Time (JIT) kullanıcı oluşturmayı, güvenli hesap eşlemeyi (Account Linking) ve sıfır in-memory bağımlılığını standartlaştıran üretim kılavuzudur.

1 Mimari İlkeler ve Kimlik Federasyonu Modeli

Kurumsal mikroservis ekosistemlerinde kimlik ve yetkilendirmenin tek bir merkezden, modüler ve güvenli yönetilmesi için benimsenen temel tasarım ilkeleri.

🏗️ Hexagonal & Clean Architecture + DDD

Kullanıcı etki alanı (User Domain) veritabanı sürücülerinden ve web framework'lerinden tamamen izole edilmiştir. Entity nesneleri zengin iş kuralları barındırır (Rich Domain Model). Şifre doğrulama, sosyal hesap bağlama ve durum geçişleri entity metotları üzerinden işletilir.

🌉 Identity Broker / Federation Gateway Modeli

İç ve dış istemciler (SPA, Mobil, Mikroservisler) asla doğrudan Google veya GitHub ile iletişime geçmez. Sistemimiz, dış sağlayıcılar karşısında güvenli bir OAuth2 Client, kendi iç ekosistemi karşısında ise tek otorite olan Spring Authorization Server olarak konumlanır. Tüm JWT'ler merkezi IdP tarafından imzalanır.

🔒 Değişmezlik (Immutability) & Java Records

Tüm REST DTO'ları, Request/Response nesneleri ve Domain Event'leri Java 17/21 record tipleriyle tanımlanır. Bu sayede thread-safety garanti altına alınır, yan etkiler önlenir ve gereksiz boilerplate kod ortadan kaldırılır.

📋 Soft Delete & Tam Denetim İzi (Audit)

Kullanıcı tablolarında fiziksel silme (HARD DELETE) kesinlikle yasaklanmıştır. Silme işlemleri status='DELETED' durumuna çekilerek yapılır (@SQLDelete & @SQLRestriction). Tüm oturum ve hesap bağlama hareketleri user_audit_log tablosunda saklanır.

ℹ️
Neden Identity Broker Modeli? İç mikroservislerinizin onlarca farklı sosyal sağlayıcının (Google, GitHub, Apple vb.) public key'lerini indirmesi, token formatlarını parse etmesi veya farklı claim yapılarını yönetmesi mimari bir kabustur. Broker modeli sayesinde mikroservisler yalnızca kendi Authorization Server'ının JWKS anahtarını bilir; standart kurumsal claim'lerle (user_id, roles, auth_provider) çalışır.

2 Kabul Kriterleri (Acceptance Criteria & Security Rules)

Kurumsal SSO ve Sosyal Giriş modülünün üretim ortamında karşılaması zorunlu güvenlik ve işlevsellik sözleşmeleri:

✓

1. Karma Kimlik Yönetimi (Hybrid Identity: Local Password & Passwordless Social)

Sistem hem yerel kullanıcı adı/şifreye sahip kullanıcıları hem de yalnızca sosyal hesapla (Google/GitHub) giriş yapan şifresiz kullanıcıları destekler. Sosyal kullanıcıların password_hash alanı veritabanında NULL kalabilir; kullanıcı dilediğinde profilinden yerel parola belirleyebilir.

✓

2. Just-In-Time (JIT) Provisioning & Otomatik Rol Atama

Sosyal sağlayıcı üzerinden ilk kez başarılı giriş yapan kullanıcı için veritabanında otomatik User ve UserSocialAccount kaydı açılır. Varsayılan ROLE_USER atanır ve UserRegisteredEvent fırlatılır.

✓

3. Güvenli Account Linking & Pre-Account Takeover Koruması

Aynı e-posta adresine sahip mevcut bir yerel hesap varsa, sosyal hesap yalnızca sağlayıcıdan email_verified == true dönüyorsa otomatik eşleştirilir. Doğrulanmamış veya şüpheli e-postalarda otomatik eşleme reddedilir; hesap ele geçirme (hijacking) zafiyeti engellenir.

✓

4. Yüksek Güvenlikli Parola Hashing (Argon2id / Adaptive BCrypt)

Yerel şifrelerde donanım tabanlı saldırılara (GPU/ASIC) karşı dirençli Argon2id (veya en az cost 12 BCrypt) kullanılır. Düz metin parolalar loglara veya heap dump'lara asla yansıtılmaz.

✓

5. PII Maskeleme & Brute-Force Kilitleme

Tüm log çıktılarında e-posta, kimlik numarası ve token'lar maskelenir. 5 ardışık başarısız yerel oturum açma denemesinde hesap 15 dakika boyunca geçici olarak kilitlenir (LOCKED / locked_until).

CREATE TABLE IF NOT EXISTS users (
    id UUID NOT NULL PRIMARY KEY,
    email VARCHAR(255) NOT NULL,
    password_hash VARCHAR(255) DEFAULT NULL, -- Sosyal kullanıcılar için NULL kalabilir!
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100) NOT NULL,
    status VARCHAR(30) NOT NULL DEFAULT 'ACTIVE', -- PENDING_VERIFICATION, ACTIVE, LOCKED, DELETED
    failed_attempts INT NOT NULL DEFAULT 0,
    locked_until TIMESTAMPTZ DEFAULT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    version BIGINT NOT NULL DEFAULT 0 -- Optimistic Locking
);

package com.enterprise.identity.domain;

import jakarta.persistence.*;
import org.hibernate.annotations.SQLDelete;
import org.hibernate.annotations.SQLRestriction;

import java.time.Instant;
import java.util.*;

@Entity
@Table(name = "users")
@SQLDelete(sql = "UPDATE users SET status = 'DELETED', updated_at = CURRENT_TIMESTAMP WHERE id = ? AND version = ?")
@SQLRestriction("status != 'DELETED'")
public class User {

    @Id
    private UUID id;

    @Column(nullable = false)
    private String email;

    @Column(name = "password_hash")
    private String passwordHash; // Sosyal kullanıcılar için NULL olabilir

    @Column(name = "first_name", nullable = false)
    private String firstName;

    @Column(name = "last_name", nullable = false)
    private String lastName;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private UserStatus status;

    @Column(name = "failed_attempts", nullable = false)
    private int failedAttempts;

    @Column(name = "locked_until")
    private Instant lockedUntil;

    @Column(name = "created_at", nullable = false, updatable = false)
    private Instant createdAt;

    @Column(name = "updated_at", nullable = false)
    private Instant updatedAt;

    @Version
    private Long version;

    @OneToMany(mappedBy = "user", cascade = CascadeType.ALL, orphanRemoval = true, fetch = FetchType.LAZY)
    private Set<UserSocialAccount> socialAccounts = new HashSet<>();

    @ManyToMany(fetch = FetchType.EAGER)
    @JoinTable(
            name = "users_roles",
            joinColumns = @JoinColumn(name = "user_id"),
            inverseJoinColumns = @JoinColumn(name = "role_id")
    )
    private Set<Role> roles = new HashSet<>();

    protected User() {}

    public User(UUID id, String email, String passwordHash, String firstName, String lastName) {
        this.id = id != null ? id : UUID.randomUUID();
        this.email = email.toLowerCase().trim();
        this.passwordHash = passwordHash;
        this.firstName = firstName;
        this.lastName = lastName;
        this.status = UserStatus.ACTIVE;
        this.failedAttempts = 0;
        this.createdAt = Instant.now();
        this.updatedAt = Instant.now();
    }

    public boolean hasLocalPassword() {
        return this.passwordHash != null && !this.passwordHash.isBlank();
    }

    public void setPassword(String newPasswordHash) {
        this.passwordHash = Objects.requireNonNull(newPasswordHash, "Password hash cannot be null");
        this.updatedAt = Instant.now();
    }

    public void linkSocialAccount(String provider, String providerUserId, String providerEmail) {
        boolean exists = socialAccounts.stream()
                .anyMatch(sa -> sa.getProvider().equalsIgnoreCase(provider));
        if (exists) {
            throw new IllegalStateException("Provider " + provider + " is already linked to this user");
        }
        UserSocialAccount account = new UserSocialAccount(UUID.randomUUID(), this, provider.toUpperCase(), providerUserId, providerEmail);
        this.socialAccounts.add(account);
        this.updatedAt = Instant.now();
    }

    public void unlinkSocialAccount(String provider) {
        if (!hasLocalPassword() && this.socialAccounts.size() <= 1) {
            throw new IllegalStateException("Cannot unlink the only login method. Please set a local password first.");
        }
        this.socialAccounts.removeIf(sa -> sa.getProvider().equalsIgnoreCase(provider));
        this.updatedAt = Instant.now();
    }

    // Getters and helper methods
    public UUID getId() { return id; }
    public String getEmail() { return email; }
    public String getPasswordHash() { return passwordHash; }
    public String getFirstName() { return firstName; }
    public String getLastName() { return lastName; }
    public UserStatus getStatus() { return status; }
    public Set<UserSocialAccount> getSocialAccounts() { return Collections.unmodifiableSet(socialAccounts); }
    public Set<Role> getRoles() { return Collections.unmodifiableSet(roles); }
    public void addRole(Role role) { this.roles.add(role); }
}

com/enterprise/identity/service/CustomOAuth2UserService.java 
package com.enterprise.identity.service;

import com.enterprise.identity.domain.Role;
import com.enterprise.identity.domain.User;
import com.enterprise.identity.domain.UserSocialAccount;
import com.enterprise.identity.event.SocialAccountLinkedEvent;
import com.enterprise.identity.event.UserRegisteredEvent;
import com.enterprise.identity.repository.RoleRepository;
import com.enterprise.identity.repository.UserRepository;
import com.enterprise.identity.repository.UserSocialAccountRepository;
import org.springframework.context.ApplicationEventPublisher;
import org.springframework.core.ParameterizedTypeReference;
import org.springframework.http.*;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.oauth2.client.userinfo.DefaultOAuth2UserService;
import org.springframework.security.oauth2.client.userinfo.OAuth2UserRequest;
import org.springframework.security.oauth2.core.OAuth2AuthenticationException;
import org.springframework.security.oauth2.core.OAuth2Error;
import org.springframework.security.oauth2.core.user.DefaultOAuth2User;
import org.springframework.security.oauth2.core.user.OAuth2User;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.web.client.RestTemplate;

import java.util.*;
import java.util.stream.Collectors;

@Service
public class CustomOAuth2UserService extends DefaultOAuth2UserService {

    private final UserRepository userRepository;
    private final UserSocialAccountRepository socialAccountRepository;
    private final RoleRepository roleRepository;
    private final ApplicationEventPublisher eventPublisher;
    private final RestTemplate restTemplate = new RestTemplate();

    public CustomOAuth2UserService(UserRepository userRepository,
                                   UserSocialAccountRepository socialAccountRepository,
                                   RoleRepository roleRepository,
                                   ApplicationEventPublisher eventPublisher) {
        this.userRepository = userRepository;
        this.socialAccountRepository = socialAccountRepository;
        this.roleRepository = roleRepository;
        this.eventPublisher = eventPublisher;
    }

    @Override
    @Transactional
    public OAuth2User loadUser(OAuth2UserRequest userRequest) throws OAuth2AuthenticationException {
        OAuth2User oAuth2User = super.loadUser(userRequest);
        String registrationId = userRequest.getClientRegistration().getRegistrationId().toUpperCase();

        // 1. Profil Bilgilerini Sağlayıcıya Göre Ayrıştır (Parsing)
        FederatedProfile profile = extractProfile(registrationId, oAuth2User, userRequest);

        // 2. Pre-Account Takeover Koruması: E-posta doğrulanmış mı?
        if (!profile.isEmailVerified()) {
            throw new OAuth2AuthenticationException(new OAuth2Error("email_not_verified"),
                    "Sosyal sağlayıcı e-posta adresini doğrulamadığı için hesap ilişkilendirilemez: " + profile.email());
        }

        // 3. JIT Provisioning ve Güvenli Hesap Eşleme (Account Linking)
        User user = resolveOrCreateUser(profile);

        // 4. Kurumsal Granted Authorities Listesini Oluştur
        Set<SimpleGrantedAuthority> authorities = user.getRoles().stream()
                .map(r -> new SimpleGrantedAuthority(r.getId()))
                .collect(Collectors.toSet());

        Map<String, Object> attributes = new HashMap<>(oAuth2User.getAttributes());
        attributes.put("user_id", user.getId().toString());
        attributes.put("auth_provider", profile.provider());

        String nameAttributeKey = userRequest.getClientRegistration()
                .getProviderDetails().getUserInfoEndpoint().getUserNameAttributeName();

        return new DefaultOAuth2User(authorities, attributes, nameAttributeKey);
    }

    private User resolveOrCreateUser(FederatedProfile profile) {
        // A. Sosyal hesap zaten bağlı mı?
        Optional<UserSocialAccount> existingSocial = socialAccountRepository
                .findByProviderAndProviderUserId(profile.provider(), profile.providerUserId());

        if (existingSocial.isPresent()) {
            return existingSocial.get().getUser();
        }

        // B. Aynı e-postaya sahip yerel kullanıcı var mı? (Account Linking)
        Optional<User> existingUser = userRepository.findByEmailIgnoreCase(profile.email());

        if (existingUser.isPresent()) {
            User user = existingUser.get();
            user.linkSocialAccount(profile.provider(), profile.providerUserId(), profile.email());
            userRepository.save(user);
            eventPublisher.publishEvent(new SocialAccountLinkedEvent(user.getId(), profile.provider(), profile.email()));
            return user;
        }

        // C. Yeni Kullanıcı Oluştur (Just-In-Time Provisioning)
        User newUser = new User(UUID.randomUUID(), profile.email(), null, profile.firstName(), profile.lastName());
        Role userRole = roleRepository.findById("ROLE_USER")
                .orElseGet(() -> roleRepository.save(new Role("ROLE_USER", "Standart Kullanıcı")));
        newUser.addRole(userRole);
        newUser.linkSocialAccount(profile.provider(), profile.providerUserId(), profile.email());

        User savedUser = userRepository.save(newUser);
        eventPublisher.publishEvent(new UserRegisteredEvent(savedUser.getId(), savedUser.getEmail(), "FEDERATED_" + profile.provider()));
        return savedUser;
    }

    private FederatedProfile extractProfile(String provider, OAuth2User oAuth2User, OAuth2UserRequest request) {
        if ("GOOGLE".equals(provider)) {
            String sub = oAuth2User.getAttribute("sub");
            String email = oAuth2User.getAttribute("email");
            Boolean emailVerified = oAuth2User.getAttribute("email_verified");
            String givenName = oAuth2User.getAttribute("given_name");
            String familyName = oAuth2User.getAttribute("family_name");
            return new FederatedProfile("GOOGLE", sub, email, Boolean.TRUE.equals(emailVerified),
                    givenName != null ? givenName : "GoogleUser", familyName != null ? familyName : "");
        } else if ("GITHUB".equals(provider)) {
            String id = String.valueOf(oAuth2User.getAttribute("id"));
            String name = oAuth2User.getAttribute("name");
            String[] names = (name != null ? name : "GitHub User").split(" ", 2);
            String firstName = names[0];
            String lastName = names.length > 1 ? names[1] : "";

            // GitHub e-posta private olabilir; /user/emails uç noktasına sorgu at
            String token = request.getAccessToken().getTokenValue();
            VerifiedEmail verifiedEmail = fetchGitHubPrimaryVerifiedEmail(token);

            return new FederatedProfile("GITHUB", id, verifiedEmail.email(), verifiedEmail.verified(), firstName, lastName);
        }
        throw new OAuth2AuthenticationException("Desteklenmeyen sağlayıcı: " + provider);
    }

    private VerifiedEmail fetchGitHubPrimaryVerifiedEmail(String accessToken) {
        try {
            HttpHeaders headers = new HttpHeaders();
            headers.setBearerAuth(accessToken);
            HttpEntity<Void> entity = new HttpEntity<>(headers);

            ResponseEntity<List<Map<String, Object>>> response = restTemplate.exchange(
                    "https://api.github.com/user/emails",
                    HttpMethod.GET,
                    entity,
                    new ParameterizedTypeReference<>() {}
            );

            if (response.getBody() != null) {
                for (Map<String, Object> emailEntry : response.getBody()) {
                    boolean primary = Boolean.TRUE.equals(emailEntry.get("primary"));
                    boolean verified = Boolean.TRUE.equals(emailEntry.get("verified"));
                    if (primary && verified) {
                        return new VerifiedEmail((String) emailEntry.get("email"), true);
                    }
                }
            }
        } catch (Exception ignored) {}
        return new VerifiedEmail("no-verified-email@github.internal", false);
    }

    public record FederatedProfile(String provider, String providerUserId, String email, boolean isEmailVerified, String firstName, String lastName) {}
    public record VerifiedEmail(String email, boolean verified) {}
}

                                        HttpServletResponse response,
                                        Authentication authentication) throws IOException, ServletException {

            String userIdStr = (String) oauth2User.getAttributes().get("user_id");
            String authProvider = (String) oauth2User.getAttributes().get("auth_provider");

                    "SOCIAL_" + (authProvider != null ? authProvider : "OAUTH2"),
                    "LOGIN_SUCCESS",
                    ipAddress,
                    userAgent,
                    "Başarılı federated login oturumu"

        }

    }

        String xForwardedFor = request.getHeader("X-Forwarded-For");
        if (xForwardedFor != null && !xForwardedFor.isBlank()) {
            return xForwardedFor.split(",")[0].trim();
        }
        return request.getRemoteAddr();
    }

com/enterprise/identity/token/CustomTokenCustomizer.java 
package com.enterprise.identity.token;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.GrantedAuthority;
import org.springframework.security.oauth2.core.user.OAuth2User;
import org.springframework.security.oauth2.server.authorization.OAuth2TokenType;
import org.springframework.security.oauth2.server.authorization.token.JwtEncodingContext;
import org.springframework.security.oauth2.server.authorization.token.OAuth2TokenCustomizer;

import java.util.Set;
import java.util.stream.Collectors;

@Configuration
public class CustomTokenCustomizer {

    @Bean
    public OAuth2TokenCustomizer<JwtEncodingContext> tokenCustomizer() {
        return context -> {
            Authentication principal = context.getPrincipal();

            // Kullanıcının sistemdeki tüm rolleri
            Set<String> roles = principal.getAuthorities().stream()
                    .map(GrantedAuthority::getAuthority)
                    .collect(Collectors.toSet());

            // Kullanıcının kimlik tipi (LOCAL, GOOGLE, GITHUB)
            String authProvider = "LOCAL";
            String userId = principal.getName();

            if (principal.getPrincipal() instanceof OAuth2User oauth2User) {
                if (oauth2User.getAttributes().containsKey("auth_provider")) {
                    authProvider = (String) oauth2User.getAttributes().get("auth_provider");
                }
                if (oauth2User.getAttributes().containsKey("user_id")) {
                    userId = (String) oauth2User.getAttributes().get("user_id");
                }
            }

            final String finalAuthProvider = authProvider;
            final String finalUserId = userId;

            if (OAuth2TokenType.ACCESS_TOKEN.equals(context.getTokenType())) {
                context.getClaims().claims(claims -> {
                    claims.put("user_id", finalUserId);
                    claims.put("roles", roles);
                    claims.put("auth_provider", finalAuthProvider);
                    claims.put("tenant_id", "enterprise-corp");
                    claims.put("iss_type", "internal-identity-broker");
                });
            }

            if (OAuth2TokenType.ID_TOKEN.equals(context.getTokenType())) {
                context.getClaims().claims(claims -> {
                    claims.put("user_id", finalUserId);
                    claims.put("roles", roles);
                    claims.put("auth_provider", finalAuthProvider);
                });
            }
        };
    }
}

        problem.setTitle("Geçersiz İş Mantığı Durumu");
        problem.setType(URI.create("https://identity.enterprise.com/errors/illegal-state"));
        problem.setProperty("timestamp", Instant.now());
        return problem;

9 Güvenlik Tehdit Modeli ve Çözüm Tablosu

Federated kimlik ve SSO mimarilerinde en sık karşılaşılan saldırı vektörleri ve kurumsal mitigasyon stratejileri:

Tehdit (Threat) Risk Açıklaması Kurumsal Çözüm / Mitigasyon
Pre-Account Takeover Saldırgan kurbanın e-postasıyla şifresiz sahte bir Google/GitHub hesabı açıp yetki kazanmaya çalışır. Sağlayıcıdan gelen email_verified == true kontrolü olmadan asla otomatik linkleme yapılmaz. Doğrulanmamışsa oturum reddedilir.
Passwordless Lockout Sosyal hesabını silen veya erişimini kaybeden kullanıcı yerel şifresi yoksa sonsuza dek kilitlenir. Kullanıcıya profilinden "Set Local Password" opsiyonu sunulur; tek oturum yöntemi kalan sosyal bağlantı silinemez.
Insecure Direct Token Exposure Access token'ın tarayıcı LocalStorage'da tutulup XSS ile çalınması. BFF (Backend-For-Frontend) deseni kullanılır veya token'lar HttpOnly, Secure, SameSite=Strict cookie ile saklanır.
OAuth Callback CSRF Yetkilendirme akışında dönen authorization code'un sahte bir oturuma enjekte edilmesi. Spring Security OAuth2 Client'ın yerleşik rastgele state parametresi ve PKCE zorunluluğu ile korunur.
Credential Stuffing & Brute-Force Otomatik botlarla yerel kullanıcı şifrelerinin taranması. Argon2id hashing, 5 ardışık başarısız denemede hesap kilitleme (locked_until) ve IP tabanlı rate-limiting.
